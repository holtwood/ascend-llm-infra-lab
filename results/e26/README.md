# E26 — 调度器/配置矩阵：4 节点同刻各跑一臂

> 面试题：**"调度器/编译配置怎么选？"**
> 方法：4 台 910B2 同一时刻各跑一种配置、同一负载（c16/n64/in256/out96）——
> 一次墙钟出四行表，排除时间漂移。**注意**：臂间跨节点，存在 11% 节点
> 差异（E21），结论只取远超噪声的差值。

## 数据（同刻四机）

| 臂 | 节点 | 输出吞吐 | TPOT | 相对 default |
|---|---|---|---|---|
| default（async 开） | M1 | **800.6 tok/s** | 16.5ms | 1.00× |
| short_request_first | M3 | 665.3 | 19.0ms | 0.83× |
| async 关（`--no-async-scheduling`） | D | 499.5 | 25.4ms | **0.62×** |
| MTP k=1 | M2 | 193.5 | 52.1ms | **0.24×** |

## 机制解释

1. **async 关 −38%**：与 E11 同节点 A/B（+60% / −39%）方向一致；
   调度与模型步流水线重叠的收益，在跨节点口径下依然远超噪声。
2. **SRF 0.83×**：SRF 只对**长短混合**负载有效（E19 同节点 short −7.2%）；
   本负载同长度 → 分道无收益，−17% 在节点差异边缘。
3. **MTP 0.24×**：与 E14/E15/E24 的负收益结论一致（跨节点仍大幅低于基线）。

## 面试口径

- "配置矩阵可以四机同刻跑——但**跨节点对比必须先有节点基线**（E21 的 11%）；
  差值在 10% 内的一律不可信，我这次只采信 −38%/−76% 两个"
- "SRF 的收益条件是长短混合；同构负载下它没有用武之地"（机制而非调参）

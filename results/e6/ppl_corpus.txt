大语言模型推理系统的性能优化通常围绕两条主线展开：降低每步计算的算力消耗，以及减少显存带宽的瓶颈效应。在自回归解码阶段，每个token的生成都需要完整读取一遍模型权重，因此小batch下的decode天然是memory-bandwidth bound的。量化技术正是利用这一点，将fp16或bf16权重压缩为int8甚至int4，在几乎不损失精度的前提下显著降低带宽压力。然而在batch较大时，计算密度上升，系统逐渐转为compute-bound，此时量化带来的收益会减弱，甚至因为反量化开销而出现负收益。

现代操作系统中的虚拟内存管理为KV cache的高效利用提供了直接类比。PagedAttention借鉴分页思想，将注意力缓存划分为固定大小的block，通过block table进行间接寻址。这种设计将显存碎片率从接近百分之五十压低至个位数，使得更大的batch size成为可能。调度器在每个迭代步中动态决定哪些请求进入执行序列，这正是continuous batching相对于静态批处理的核心优势。

The transformer architecture has become the dominant paradigm in natural language processing since its introduction. Unlike recurrent networks that process tokens sequentially, the transformer relies entirely on self-attention mechanisms, allowing it to capture long-range dependencies in parallel. Each layer consists of multi-head attention followed by position-wise feed-forward networks, with residual connections and layer normalization stabilizing training. The attention operation scales quadratically with sequence length, which has motivated extensive research into sparse, linear, and low-rank approximations.

Distributed training frameworks must carefully orchestrate communication primitives to keep accelerators busy. All-reduce aggregates gradients across workers, while all-gather and reduce-scatter handle sharded parameters in data-parallel schemes like ZeRO. When the communication fabric is limited to TCP over Ethernet rather than dedicated interconnects, gradient synchronization can dominate step time. Practitioners therefore overlap communication with backward computation, bucket gradients, and quantize or sparsify updates to reduce transferred bytes.

def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.cache = {}
        self.order = []

    def get(self, key):
        if key not in self.cache:
            return -1
        self.order.remove(key)
        self.order.append(key)
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.order.remove(key)
        elif len(self.cache) >= self.cap:
            oldest = self.order.pop(0)
            del self.cache[oldest]
        self.cache[key] = value
        self.order.append(key)

The key insight behind speculative decoding is that verifying multiple draft tokens costs the same as generating one, because the target model's forward pass runs in parallel over the draft sequence. If the draft model proposes tokens the target would have generated anyway, throughput multiplies without changing output distribution. Acceptance rate depends on how closely the draft approximates the target; self-drafting methods like Medusa and EAGLE train lightweight heads on the target's own hidden states to achieve high agreement.

TCP congestion control evolved from Tahoe through Reno to modern variants like CUBIC and BBR. The core idea is an additive-increase multiplicative-decrease loop that probes available bandwidth while reacting to packet loss as a congestion signal. BBR takes a different approach, modeling the bottleneck bandwidth and round-trip propagation delay explicitly, then pacing sends at the estimated bandwidth to keep queues short without collapsing throughput.

Garbage collection in the JVM divides the heap into generations: young objects die fast and are collected by minor GC with copying algorithms, while long-lived objects promote to the old generation collected by mark-sweep-compact or concurrent mark-sweep. The Raft consensus algorithm decomposes consensus into leader election, log replication, and safety. A cluster elects a single leader per term; the leader accepts client commands, appends them to its log, and replicates entries to followers. An entry is committed once stored on a majority of servers. Randomized election timeouts prevent split votes, while term numbers act as a logical clock to detect stale leaders.

In a Raft cluster, a log entry is committed once a majority of nodes have stored it. Committed entries are applied to the state machine in log order. The leader appends entries with the current term, and followers reject entries whose term is older than their own. The election restriction—that a candidate must have a log at least as up-to-date as a voter's—ensures a new leader holds every committed entry.

The CAP theorem states a distributed system cannot simultaneously guarantee consistency, availability, and partition tolerance. In practice, partitions are inevitable in wide-area deployments, so the real choice is CP versus AP. Systems like etcd and ZooKeeper choose consistency via quorum protocols, while Dynamo-style stores prefer eventual consistency with vector clocks and conflict resolution at read time.

Zero-knowledge proofs allow a prover to convince a verifier that a statement is true without revealing why. zk-SNARK constructions compress the proof to a few hundred bytes with constant-time verification, at the cost of a trusted setup ceremony. zk-STARKs remove the trusted setup using hash-based commitments and the FRI protocol, but proofs are tens of kilobytes. Both compile a computation into an arithmetic circuit, then into polynomial constraints checked via random queries.
